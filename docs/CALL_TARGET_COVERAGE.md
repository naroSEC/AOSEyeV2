# 저장 호출 대상 본문 범위 계측

새 분석이 JEB 인덱스를 받으면 provenance.call_target_coverage에 schema=1 통계를 저장한다.
백엔드 실패로 인덱스를 받지 못하면 통계를 기록하지 않는다. 구형 프로젝트는 열 때
자동으로 수정/재계산하지 않고 not recorded로 표시한다. GUI 상단에 요약을,
Diagnostics에 항목별 수치를 표시한다. 설정이나 현재 백엔드 상태로 과거 수치를 추정하지 않는다.

통계 단위는 저장된 본문의 invoke 명령 위치다. 동일 대상의 반복 호출은 각각 센다.
상속이나 실제 가상 호출 대상을 추정하지 않고 정확한 DEX 피연산자 시그니처만 비교한다.
아래 분류는 상호 배타적이며 합계는 invoke_sites다.

- body_available: 저장된 정확한 대상 본문이 있고 저장 정보에서 출처 충돌/불명이 없음.
- ambiguous_units: 선언/본문에서 서로 다른 정의 unit이 관측됨. 다른 unit의 참조만으로는 중복 정의로 보지 않음.
- unknown_origin: 본문/선언의 unit 또는 선언 여부가 불명확함.
- indexed_body_missing: 코드가 있다고 인덱스에 기록됐지만 본문이 저장되지 않음.
- declared_no_code: 코드 없는 선언으로 기록됨. abstract/native 등 이유는 추정하지 않음.
- declaration_unknown: 선언은 있으나 코드 존재 정보가 없음.
- unindexed_target: 정확한 대상 본문/정의를 저장 정보에서 찾지 못함.
- missing_operand: 대상이 없거나 메서드 참조 형태가 아님.

dynamic_dispatch_sites는 virtual/interface/custom/polymorphic opcode 수로 위 분류와
겹친다. body_available이어도 실제 런타임 대상/실행 가능성을 증명하지 않는다.
누락 후보에는 플랫폼/라이브러리 API, 상속 참조, 제외된 앱 코드 등이 섞일 수 있다.
따라서 모든 누락을 예산 탓, 취약점, 앱 전체 누락률로 해석하지 않는다.
통계만으로 finding 판정이나 complete 플래그를 변경하지 않으며 자동 본문 확장도 하지 않는다.

선언 정보와 명령을 한 번씩 훑고 256행/명령 단위 및 메서드 경계에서 취소를 확인한다.
추가 메모리는 저장된 선언/출처 수에 비례하며 호출별 목록은 생성하지 않는다.
GUI는 알려진 schema/범위, 정수/비음수, 분류 합계와 호출/명령 개수 일관성을 검사하고
불일치한 저장값은 unavailable로 표시한다. 임의 객체를 원문으로 출력하지 않는다.

## 검증

신규 11개 테스트는 모든 분류, 중복/참조 출처, 반복 호출, 동적 opcode, 상속 비추정,
취소, 구형 결과, 저장/재열기, 잘못된 정수/합계를 검사한다.
기존 실제 JEB 부분 분석 시험에 통계의 저장/재열기 보존 검사를 추가했다.
전체 회귀 **674 passed (143.33초)**, 실제 JEB 통합 15개 포함.
GUI 관련/신규 계측 테스트 28개를 별도로 통과했고 작은 창의 QML 렌더링도 확인했다.
wheel 재빌드 SHA-256:
`0b6fce9b7515dedcaa386928ad6f788f5fe9d2ddc9084fc8f5a7ac94981160df`.
독립 가상환경 설치 검증은 이번 단계에서 반복하지 않았다.

이전 amoremall 부분 프로젝트(본문 1,000개)를 읽기 전용으로 별도 계측했다.
명령 25,963개, invoke 8,672곳, body_available 735곳, unindexed_target 7,937곳,
나머지 분류 0곳. dynamic_dispatch_sites는 4,545곳이다. 계측 약 0.039초는
이 기기에서 한 번 측정한 값이며 성능 보장이 아니다. 원본 프로젝트에는 통계를 쓰지 않았다.
이 결과는 전체 APK 재분석이나 실제 호출 대상의 확인이 아니다.

후속으로 누락 분류별 위치 탐색을 구현했다(`CALL_TARGET_BROWSER.md`).
제한적 본문 확장은 설계만 기록했으며 아직 구현하지 않았다.
특히 외부 API를 앱 본문 누락으로 확정하지 않아야 한다.
