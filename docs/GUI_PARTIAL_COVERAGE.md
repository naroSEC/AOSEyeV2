complete=false이거나 저장 진단이 있으면 PARTIAL ANALYSIS로 안내한다. complete=true도
설정된 범위 내의 저장 판정임을 표시하며 전체 APK의 안전성을 의미하지 않는다.

구형 보고서와의 호환을 위해 선언 예산 진단의 정해진 숫자 패턴을 읽어 제외 항목 수를
표시한다. 중복 진단은 한 번만 표시하고, 최근 진단 범위에서 단일한 유효 기록을 확인하지
못하면 제외 총계 미확정으로 남긴다. 결과를 로드할 때만 계산하며 전체 진단에서 최신
256개씩만 확인한다. 진단이 없거나 누락됐다는 이유로 제외 수를 0으로 만들지 않는다.
배너는 일반 텍스트로 렌더링한다. 추후 구조화된 범위 메타데이터 도입 여지가 있다.

DEX 페이지의 분모는 saved matches라고 표시한다. 결과가 비었을 때는 현재 저장 인덱스의
범위/필터에 일치 항목이 없다는 뜻이며 원본 APK에 존재하지 않는다는 증거가 아님을 안내한다.

위치/근거를 바꾸거나 JEB를 호출하지 않고 안내만 남긴다. 새로운 데이터를 얻으려면
예산/수집 정책을 바꿔 다시 분석해야 한다. 원본 없이 저장 결과를 소급 보강하지 않는다.
